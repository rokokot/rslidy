🎯 Navigation & Transitions

Rslidy supports multiple slide transition types and navigation methods:

🎨 Transition Types

  • Fade: Smooth opacity transitions
  • Slide: Horizontal slide movement
  • Zoom: Scale-based transitions
  • Unanimated: Instant switching

⌨️ Keyboard Navigation

  • Arrow keys (←→↑↓)
  • Space bar (next slide)
  • Home/End (first/last)
  • Page Up/Down

👆 Touch & Mouse

  • Swipe gestures (mobile)
  • Click to advance
  • Margin tap navigation
  • Scroll wheel support
💡 Pro Tip: This presentation uses the "fade" transition. You can change it by modifying the body class: <body class="fade">

📝 Incremental Content

Content can appear progressively as you navigate through slides:

Basic Incremental List

  • 🎯 This item appears first
  • 🚀 This item appears second
  • ✨ This item appears third
  • 🎉 This item appears fourth
  • 💯 This item appears last

Nested Incremental Lists

  • 🌟 Main topic A
    • 📌 Subtopic A.1
    • 📌 Subtopic A.2
  • 🌟 Main topic B
    • 📌 Subtopic B.1
    • 📌 Subtopic B.2
  • 🌟 Main topic C
✅ How it works: Add class="incremental" to any <ul> or <ol> element.

🎛️ Configuration & Customization
