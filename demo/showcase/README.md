## 🎨 Customization

### Styling
The showcase uses CSS custom properties for theming:
```css
:root {
    --showcase-primary: #667eea;
    --showcase-secondary: #764ba2;
    --showcase-accent: #f093fb;
    /* ... */
}
```

### Content
- Modify slides by editing the HTML content
- Add new interactive demos using the existing patterns
- Extend functionality with additional JavaScript

### Configuration
Rslidy settings can be customized via JavaScript:
```javascript
window.rslidy = {
    transition: 'fade',
    image_viewer: true,
    // ... other options
};
```
